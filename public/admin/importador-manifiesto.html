🧲 Asociación automática de descargas

Etapa experimental: una URL HTTPS de manifiesto JSON autorizado, validación de enlaces Torrent/Magnet y asociación por slug con las fichas preparadas. Solo vista previa. Sin extraer torrents de páginas comerciales, sin escribir en Supabase.

Esperando URL. El servidor del manifiesto debe permitir CORS.

JuegoTipoEnlaceResultado

Formato esperado

El manifiesto debe identificar cada juego mediante su slug, declarar la autorización de distribución y aportar sus enlaces. No se aceptan datos sin declaración de permiso.

{
  "version": 1,
  "distributionAuthorized": true,
  "games": [
    {
      "slug": "juego-libre",
      "downloads": [
        { "type": "torrent", "url": "https://ejemplo.com/juego.torrent" },
        { "type": "magnet", "url": "magnet:?xt=urn:btih:..." }
      ]
    }
  ]
}

La declaración en el archivo no verifica por sí misma los derechos. Confirmá la licencia antes de publicar. Esta herramienta no descarga ni publica archivos.
